Repair History Web App (PWA)

Files: index.html, manifest.json, sw.js, icon.svg

Hosting steps (GitHub Pages):
1. Create/login to GitHub and create a new repository.
2. Upload all 4 files from this folder to the repository root.
3. Repository Settings > Pages > deploy from branch; select main and root; Save.
4. Open the generated HTTPS Pages URL on Android Chrome.
5. Chrome menu (three dots) > Install app / Add to Home screen.

Data is stored locally in that browser/device. Use the app's Backup tab regularly.
This app has no cloud sync or account login yet.
